# 🐦 Flappy Bird Game – Unity

A 2D Flappy Bird-style game developed using Unity. The player controls a bird and navigates through obstacles by jumping or flapping to avoid collisions and achieve a high score.

## 🎮 About the Project

This project recreates the basic gameplay of Flappy Bird using the Unity game engine. It demonstrates fundamental game development concepts, including player controls, collision detection, physics, obstacle navigation, and score tracking.

## ✨ Features

* 🐦 Bird movement and player controls
* 🚧 Obstacles that challenge the player
* 💥 Collision detection
* 🏆 Score tracking
* 🔄 Game-over and restart functionality
* 🎨 2D game environment

*Features listed above should be adjusted to match the functionality implemented in your game.*

## 🚀 How to Run the Project

1. Clone or download this repository.
2. Install Unity Hub and a compatible Unity Editor version.
3. Open Unity Hub.
4. Click **Add** or **Add project from disk**.
5. Select the downloaded project folder.
6. Open the project in Unity.
7. Open the main game scene from the `Assets` folder.
8. Click the **Play** button to run the game.
